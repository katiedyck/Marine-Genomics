# MB5370 Module 3: Marine Genomics

This repository contains code, data, and images from MB5370 module on marine genomics &amp; bioinformatics.

- Workshop 1: [Introduction](code/genomics_workshop1.Rmd)
- Workshop 2: [Genome Assembly](code/genomics_workshop2.Rmd)
- Workshop 3: [Metagenome Assembly](code/workshop3_MetagenomeAssembly.Rmd)
- Workshop 4: [Black Band Disease (BBD)](code/workshop4_BBD.Rmd)

My RMarkdown files for each workshop can be found in the **code** folder. `styles.css` contains formatting for my Markdown files that shows terminal bash coding in a unique formatting, making it easier to distinguish from R coding.

The [checkm](checkm), [flye](flye), [gtdbtk](gtdbtk), [metabat](metabat), [minpath](minpath) and [prokka](prokka) folders contain files from Workshop 4.
